# 漢ノ字（オトコノジ）

漢字を画（かく）ごとにばらして、自分だけの形に組み替える。その形で、地元の最強と同じしくみのぶつかり合いをする全自動の1対1。
同じ作品どうしなら、どの端末でも必ず同じ結果になる。

## あそびかた
- 字を1つ入れると、画ごとにばらばらになって「素材箱」に入る（書き順に番号つき）
- 画をドラッグで台に置き、⟲⟳で15度ずつ回す。重ねて1つの形にする（縦に積まない）
- 画は必ずどこかの画とくっつける（はなれた画は赤くなり、保存できない）。画はぜんぶ使う
- 練習試合：自分の作品 対 元の字（好きな字）
- 挑戦状：作品に8けたの合言葉（0・O・1・I は使わない）がつく。画像つきでXに投稿できる。合言葉／ランダム／リンク（?c=合言葉）で戦える
- だれかと対戦・部屋番号で対戦：その場にいる人と作品どうしで1対1（地元の最強と同じしくみ）

## 強さ
体力＝線の広さ、勢い＝元の字の画数、かたさ＝すき間の少なさ、鋭さ＝出っぱり、速さ＝軽さ（どれも元の字 約1万2千字の中の順位で 0〜100）
- 大きさはそろえてから戦う。広がりすぎた形は縮めて、体力と重さに加点（1.6倍まで）
- 画数が少ない字は細い線が欠けて落ちやすいので、画数に応じて体力を足す（`js/shape.js` の `HPX`）
- 能力の効き方は `js/sim.js` の `JM.K`
- ※強さの数字を変えると、同じ作品どうしでも結果が変わります（挑戦状の成績はそのまま残ります）

## ファイルの中身
| ファイル | 役割 |
|---|---|
| `js/glyph.js` | 字の画を読みこむ（ハングルは部品からここで作る） |
| `js/shape.js` | 置いた画 → 戦う形（マス目に塗って輪郭をとる）と強さ。端末で答えが変わらない計算だけ |
| `js/pct.js` | 強さの順位表（`tools/build-pct.js` で作る） |
| `js/sim.js` | ぶつかり割りの物理（地元の最強と同じ） |
| `js/edit.js` | 作る画面 |
| `js/main.js` | 画面と進行・作品の一覧・結果画像・投稿 |
| `js/chal.js` | 挑戦状 |
| `js/online.js` / `js/qm.js` | 部屋番号で対戦／だれかと対戦 |
| `js/render.js` / `js/resimg.js` | 描画／投稿用の画像 |
| `js/sound.js` | 効果音と音楽（音楽はその場でプログラムが鳴らす） |
| `js/firebase-config.js` | Firebase の設定（ここに貼る）と版の番号 `OK.VER` |
| `version.json` | 版の番号。`OK.VER` と同じにする。上げると開いたままの古い画面が読みなおす |
| `data/g/*.json` | 字の画（41ファイル） |
| `database.rules.json` | Firebase に貼る安全ルール |
| `tools/` | 字のデータ・順位表を作る道具、バランスの確かめ（公開には使わない） |

## 管理
- 挑戦状を出さなくする：Firebase の画面 → Realtime Database → `ok_chal/{合言葉}` に `x` を `true` で足す（消してもよい）
- 書きこみは匿名ログイン。連投の制限：挑戦状は15秒に1回、成績は4秒に1回（ルールで制限）

## データ
- 日本の字形：KanjiVG（Ulrich Apel、CC BY-SA 3.0）を加工して作成
- 中国・台湾の字形：Make Me a Hanzi（Shaunak Kishore）／hanzi-writer-data（Arphic Public License）を加工して作成
- 英数字：Hershey フォント（hersheytext、MIT License）を加工して作成
- 加工した画のデータ（`data/g`）は、もとのデータと同じ条件（CC BY-SA 3.0・Arphic Public License）で公開しています
- 効果音：Kenney「Impact Sounds」（CC0）　音楽：自作（プログラムで作成）
